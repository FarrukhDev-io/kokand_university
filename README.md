# Kokand University Website

Qo‘qon Universitetining (Kokand University) rasmiy yoki taqdimot veb-sayti. Loyiha Vite, React va TypeScript texnologiyalari yordamega zamonaviy dizayn hamda ilg'or UI komponentlar (Shadcn UI, Tailwind) asosida qurilgan.

## 🌟 Loyiha Haqida

Ushbu veb-sayt universitetning ta'lim yo'nalishlari, talabalar hayoti, xalqaro dasturlar va qabul jarayonlari haqida ma'lumot beradi. Sayt mukammal SEO (qidiruv tizimlariga moslashtirish) va ijtimoiy tarmoqlar uchun Open Graph meta-teglari bilan ta'minlangan.

## 🚀 Asosiy Imkoniyatlar & Strukturasi
* **Zamonaviy UI:** Shadcn UI va Radix UI komponentlaridan foydalanilgan.
* **Kengaytirilgan SEO:** Qidiruv tizimlarida birinchi o'rinlarda chiqish uchun optimallashtirilgan meta teglari.
* **Responsive & Tezkor:** Vite va Bun yordamida tezkor yuklanish va moslashuvchanlik.

## 🛠 Texnik Stack
* **Framework:** React (Vite yordamida yig'ilgan)
* **Dasturlash tili:** TypeScript
* **Stillashtirish:** TailwindCSS, PostCSS
* **UI kutubxonalar:** Radix UI, Shadcn UI, TanStack kutubxonalari.
